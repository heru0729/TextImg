How to Use TextImg

TextImg is a free, browser-based tool for creating custom text images. No account, no installation, no watermark. This guide covers every feature in detail so you can get the most out of it.

1. Getting Started

No sign-up, no installation required

TextImg runs entirely in your browser. Simply visit textimg.net and start creating immediately. Your settings are automatically saved to your browser's local storage, so your work is preserved even if you close the tab.

The interface is divided into two main areas: the sidebar on the left where you configure all settings, and the canvas preview on the right where you can see your image in real time.

Choosing a Mode

At the top of the sidebar, you'll find three mode buttons:

  • Text — The main mode. Type text and customize its appearance.
  • 5000 — Generate images in the "5000 Choyen" meme style.
  • Dot — Draw pixel art directly on the canvas.

TextImg always opens in Text mode, regardless of the last mode you used.

Navigating the Canvas

The preview canvas supports zoom and pan:

  • Zoom: Scroll the mouse wheel over the canvas, or use the − / ＋ buttons at the bottom right.
  • Pan: Click and drag on the canvas background.
  • Reset view: Click the ⌖ button to return to center at 100%.
  • Mobile: Pinch to zoom, one-finger drag to pan.

2. Text Mode

The core feature of TextImg

In Text mode, type anything into the input field and it appears on the canvas instantly. You can enter multiple lines by pressing Enter.

Text Input

The text input area supports multi-line text. Each line is rendered separately on the canvas. There is no character limit enforced by the app, but very long texts may extend beyond the canvas boundaries — adjust the font size or image dimensions accordingly.

Alignment

You can control how text is positioned on the canvas:

  • Horizontal alignment: Left, Center, or Right.
  • Vertical alignment: Top, Middle, or Bottom.

Custom Position & Drag

For precise control, enable Custom position by checking the "Enable drag" checkbox. You can then:

  • Enter exact X and Y pixel coordinates in the input fields.
  • Click and drag the text directly on the canvas to reposition it freely.
Tip: Custom position overrides horizontal and vertical alignment settings. Uncheck it to return to alignment-based positioning.

Flip (Mirror)

Use the ↔ and ↕ buttons next to Bold/Italic to flip text horizontally or vertically. Both can be enabled at the same time for a 180° rotation effect.

3. Font & Style

Japanese and Latin typefaces included

TextImg includes several high-quality Google Fonts, with a focus on Japanese-compatible typefaces:

Noto Sans JP

Clean, modern sans-serif. Ideal for general use, UI screenshots, and social media.

Noto Serif JP

Elegant serif typeface. Great for formal or literary aesthetics.

M PLUS Rounded 1c

Friendly, rounded sans-serif. Perfect for casual or cute designs.

Dela Gothic One

Bold, impactful display font. Great for titles and attention-grabbing text.

Zen Kaku Gothic New

Geometric sans-serif with a modern feel. Works well for minimal designs.

serif / monospace

Browser-native fallbacks for maximum compatibility.

Font Size

Drag the size slider to set font size from 8px to 300px. The current value is shown next to the label. For very large text on small canvases, the text may be clipped — increase canvas dimensions or reduce padding.

Line Height

Controls the vertical spacing between lines. The value is a multiplier of the font size (e.g., 1.4 means 1.4× the font size). Range: 0.8 to 3.0.

Bold & Italic

Toggle Bold and Italic independently. Note that not all fonts support italic rendering — the browser will simulate it if a true italic variant is unavailable.

4. Color Settings

Full color control for background and text

Background & Text Color

Click the color swatch to open a color picker, or type a hex code directly (e.g. #ff0000). Changes apply immediately to the canvas.

Per-Character Color

Enable Per-character color to assign a unique color to each character. A row of small color pickers appears — one per character in your text. This is useful for rainbow text or highlighting specific letters.

Tip: Per-character color and Gaming Text are mutually exclusive. Enabling one disables the other.

Gaming Text 🌈

Enable Gaming Text to apply a smooth rainbow gradient across the entire text automatically. This is a quick way to create colorful, eye-catching text without setting colors manually.

5. Effects

Six built-in effects to enhance your text

Each effect has its own expandable panel. Click the panel header to expand settings, and check the checkbox to enable the effect. Multiple effects can be combined.

Pixel Mode

Renders the canvas at a reduced resolution and scales it back up, creating a pixelated / retro look. Adjust the Pixel size slider (2–32px) to control how blocky the result appears. Larger values = more pixelation.

Outline

Adds a stroke around each character. Set the Width (1–20px) and choose an outline color. Useful for making text readable over complex or light backgrounds.

Shadow

Adds a drop shadow behind the text. Configure:

  • Blur: How soft or hard the shadow edge is (0 = sharp, 40 = very soft).
  • X / Y offset: Shadow direction. Positive X moves it right, positive Y moves it down.
  • Color: Shadow color (usually black or a dark version of the text color).

Glitch

Applies a randomized glitch / data-corruption visual effect. The Amount slider controls how strong the distortion is. Because it's randomized, the result changes slightly each time you re-render (e.g., by changing any other setting).

Gradient Text

Fills the text with a linear color gradient instead of a solid color. Choose two colors and a direction:

  • Horizontal: Gradient flows left to right.
  • Vertical: Gradient flows top to bottom across all lines.
  • Diagonal: Gradient flows from top-left to bottom-right.
Tip: Gradient Text is disabled when Per-character color or Gaming Text is active.

Neon

Simulates a neon glow effect by rendering a colored blur behind the text. Adjust Glow size (5–50px) and Glow color. Works best with a dark or black background.

6. Image Size & Padding

Create images for any platform

Preset Sizes

Six presets are available for common use cases:

  • 800×600 — General purpose.
  • 1200×630 — OGP (Open Graph Protocol) for link previews on social media.
  • 1080×1080 — Square format for Instagram and other social posts.
  • 1920×1080 — Full HD (FHD), suitable for presentations and wallpapers.
  • 1080×1920 — Portrait (Stories format for Instagram, TikTok, etc.).
  • 1500×500 — Wide banner format.

Custom Size

Enter any width and height (1–4000px) in the input fields. The canvas will resize immediately. Very large canvases may be slow to render on low-end devices.

Padding

Controls the margin between the text and the canvas edge when using alignment-based positioning (not custom position). Range: 0–200px. Increasing padding moves text away from the edges for a cleaner look.

7. 5000 Choyen Mode

Generate the "5000兆円欲しい！" meme-style image

This mode uses the external gsapi.cbrx.io API to generate a stylized two-line image in the well-known internet meme format.

  1. Enter top text — Typically a large number or phrase (e.g. "5000兆円").

  2. Enter bottom text — A short phrase below (e.g. "欲しい！").

  3. Optionally enable Rainbow for a colorful variant.

  4. Click Generate. The image loads and appears both in the preview and in the panel.

  5. Use the Width slider and X / Y sliders — or drag the image directly on the canvas — to position it.

Note: Generation requires an internet connection. If it fails, the external API may be temporarily unavailable.

8. Dot Mode

Draw pixel art directly on the canvas

Dot Mode turns the canvas into a pixel art editor. It can be combined with text from Text Mode since both render on the same canvas.

How to Draw

  1. Switch to Dot mode using the top mode buttons.

  2. Set the Grid size (4–64px). This determines the size of each dot.

  3. Choose a Dot color.

  4. Click on the canvas to place a dot. Click the same cell again to erase it.

  5. Click and drag to draw continuously.

Grid Visibility

Check Show grid to display a faint grid overlay. This helps with alignment and is hidden in the exported image.

Clear All Dots

Click 🗑 Clear dots to erase all dots at once. This cannot be undone.

Tip: Dot Mode and Text Mode share the same canvas. Switch to Text Mode, type some text, then switch back to Dot Mode to add pixel art around your text.

9. Saving & Exporting

Download your image in multiple formats

File Formats

  • PNG — Lossless. Best for images with sharp edges, text, and transparency. Default choice.
  • JPEG — Lossy compression. Smaller file size, but not ideal for text (may show artifacts). Good for photos.
  • WebP — Modern format with excellent compression. Supported by all modern browsers.

Downloading

  1. Select a format from the dropdown (PNG / JPEG / WebP).

  2. Click ⬇ Save. The file downloads automatically as textimg.png (or the chosen format).

On iPhone / iPad

Due to iOS restrictions, a modal appears with a preview of your image. Long-press the image and select "Add to Photos" or "Save Image" to save it to your camera roll.

Auto Save

All settings (text, font, colors, effects, canvas size, etc.) are automatically saved to your browser's local storage approximately 0.8 seconds after any change. When you revisit TextImg, your previous settings are restored instantly. Note: mode is always reset to Text on load.

Reset

Click ↺ Reset all to clear all saved settings and reload the app with defaults. This action cannot be undone.

11. FAQ

Is TextImg really free? ▼
Yes. TextImg is completely free to use with no account required, no watermark, and no usage limits. The site is supported by ads.
Can I use the images commercially? ▼
Yes. Images you create with TextImg belong to you. However, you are responsible for ensuring that the fonts and content you use do not infringe any third-party rights.
Is my text uploaded to any server? ▼
No. All rendering happens locally in your browser using the HTML Canvas API. Your text never leaves your device — except in 5000 Choyen Mode, which sends your input to an external API to generate the image.
Why does the image look blurry when I zoom in on the canvas? ▼
The canvas zoom is for preview only and does not affect the actual image resolution. The downloaded image will always be at the exact pixel dimensions you specified (e.g., 800×600).
Can I add my own fonts? ▼
Not currently. TextImg provides a curated set of Google Fonts. Custom font support may be added in a future update.
The 5000 Choyen generation failed. What should I do? ▼
This mode relies on an external API (gsapi.cbrx.io). If it fails, the API may be temporarily unavailable. Please try again later. TextImg is not responsible for third-party service availability.
My settings were lost. Why? ▼
Settings are saved to your browser's local storage. They may be cleared if you use private / incognito mode, clear browser data, or use a different browser or device.

1. はじめに

アカウント不要・すぐに使える

textimg.net にアクセスするだけで、すぐに使い始められます。設定はブラウザのローカルストレージに自動保存されるため、タブを閉じても次回訪問時に復元されます。

画面は大きく2つに分かれています。左側のサイドバーで各種設定を行い、右側のキャンバスプレビューでリアルタイムに確認できます。

モードの選択

サイドバー上部にある3つのボタンでモードを切り替えます：

  • テキスト — メインモード。テキストを入力して画像を作成します。
  • 5000 — 「5000兆円欲しい！」スタイルの画像を生成します。
  • ドット — キャンバスに直接ピクセルアートを描きます。

TextImgは常にテキストモードで起動します。

キャンバスの操作

  • ズーム：マウスホイールを回す、または右下の−/＋ボタン。
  • パン（移動）：キャンバス背景をクリック＆ドラッグ。
  • リセット：⌖ボタンで中央・100%に戻す。
  • スマホ：ピンチでズーム、1本指ドラッグでパン。

2. テキストモード

TextImgのメイン機能

テキストモードでは、入力欄に文字を入力するとキャンバスにリアルタイムで反映されます。Enterキーで改行でき、複数行のテキストも作成できます。

配置（アライメント）

  • 水平：左寄せ・中央・右寄せ
  • 垂直：上・中央・下

位置指定・ドラッグ移動

「ドラッグで移動」のチェックボックスをオンにすると、テキストの位置を自由に制御できます：

  • X・Y座標（px）を直接入力して指定
  • キャンバス上でテキストをドラッグして直感的に移動
ヒント：カスタム位置モードはアライメント設定を無効にします。チェックを外すとアライメント基準に戻ります。

反転（ミラー）

太字・斜体ボタンの横にある↔（左右反転）と↕（上下反転）ボタンでテキストを鏡像化できます。両方同時にオンにすると180°回転と同じ効果になります。

3. フォント・スタイル

日本語対応フォントを収録

Noto Sans JP

シンプルなゴシック体。汎用性が高くSNSやUI画像に最適。

Noto Serif JP

上品な明朝体。フォーマルや文芸的なデザインに。

M PLUS Rounded 1c

丸みのあるゴシック体。カジュアルでかわいい印象に。

Dela Gothic One

インパクト抜群の極太ディスプレイ体。タイトルに。

Zen Kaku Gothic New

幾何学的でモダンなゴシック体。シンプルなデザインに。

serif / monospace

ブラウザ標準フォント。最大互換性が必要なときに。

フォントサイズ

スライダーで8〜300pxの範囲で調整できます。大きいサイズのテキストがキャンバスからはみ出す場合は、画像サイズを拡大するかパディングを減らしてください。

行間

フォントサイズに対する倍率で指定します（例：1.4 = フォントサイズの1.4倍）。0.8〜3.0の範囲で調整可能です。

太字・斜体

独立してオン/オフできます。フォントによっては斜体バリアントがなく、ブラウザが擬似的に再現する場合があります。

4. カラー設定

背景色・文字色を自由に設定

背景色・文字色

色見本をクリックしてカラーピッカーを開くか、テキストボックスに直接16進数カラーコード（例：#ff0000）を入力します。変更はリアルタイムでキャンバスに反映されます。

文字ごとに色指定

「文字ごとに色指定」をオンにすると、テキストの各文字に個別の色を設定できます。文字数分の小さなカラーピッカーが表示されます。特定の文字を強調したいときや、手動でレインボーテキストを作るときに便利です。

ヒント：文字ごとの色指定とGaming Textは同時に使えません。どちらかをオンにするともう一方はオフになります。

Gaming Text 🌈

オンにするとテキスト全体に虹色のグラデーションが自動で適用されます。手動で色を設定しなくても、一瞬でカラフルなテキストが作れます。

5. エフェクト

6種類のエフェクトを組み合わせて使用可能

各エフェクトはアコーディオンパネルになっています。パネルのヘッダーをクリックして設定を展開し、チェックボックスでオン/オフを切り替えます。複数のエフェクトを同時に適用できます。

ピクセルモード

キャンバスを一度低解像度で描画してから拡大することで、ドット絵・レトロゲーム風の見た目を作れます。ピクセルサイズ（2〜32px）が大きいほど粗くなります。

アウトライン

文字の輪郭線を描きます。太さ（1〜20px）と色を設定できます。明るい背景に白い文字を乗せるときなど、視認性を高めるのに役立ちます。

シャドウ

文字の背後にドロップシャドウを追加します：

  • ぼかし：影のエッジのぼかし量（0=くっきり、40=ソフト）
  • X / Y：影のずれ方向（正の値で右・下方向）
  • 色：影の色

グリッチ

データ破損風のノイズエフェクトをかけます。強度スライダーで歪み具合を調整します。ランダム処理のため、他の設定を変更するたびに結果が変わります。

グラデーションテキスト

テキストを単色ではなく2色のグラデーションで塗りつぶします。方向は水平・垂直・斜めから選べます。

ヒント：文字ごとの色指定やGaming Textがオンのときはグラデーションテキストは無効になります。

ネオン

テキストの背後に発光（グロウ）エフェクトを追加し、ネオンサイン風の見た目を作ります。グロウサイズ（5〜50px）とグロウカラーを設定できます。黒い背景との組み合わせが最も効果的です。

6. 画像サイズ・余白

あらゆるプラットフォームに対応

プリセットサイズ

  • 800×600 — 汎用サイズ
  • 1200×630 — OGP（SNSのリンクプレビュー）
  • 1080×1080 — 正方形（Instagram投稿など）
  • 1920×1080 — フルHD（プレゼン・壁紙など）
  • 1080×1920 — 縦長（ストーリーズ形式）
  • 1500×500 — 横長バナー

カスタムサイズ

幅・高さを1〜4000pxの範囲で自由に指定できます。入力後にキャンバスが即座にリサイズされます。

パディング（余白）

アライメント配置のときに、テキストとキャンバス端の間に設ける余白です。0〜200pxの範囲で調整できます。カスタム位置モードではパディングは無視されます。

7. 5000兆円モード

あのミームスタイルの画像を生成

外部API（gsapi.cbrx.io）を使用して、「5000兆円欲しい！」風のスタイリッシュな2段テキスト画像を生成します。

  1. 上段テキストを入力します（例：「5000兆円」）。

  2. 下段テキストを入力します（例：「欲しい！」）。

  3. 必要に応じて虹色をオンにします。

  4. 生成ボタンをクリック。画像がプレビューとパネルに表示されます。

  5. 幅スライダーとX/Yスライダー、またはキャンバス上で直接ドラッグして位置を調整します。

注意：画像の生成にはインターネット接続が必要です。失敗する場合は外部APIが一時的に利用できない可能性があります。

8. ドットモード

キャンバスに直接ピクセルアートを描く

ドットモードではキャンバスをピクセルアートエディターとして使えます。テキストモードと同じキャンバスを共有しているため、テキストとドットアートを組み合わせることもできます。

描き方

  1. 上部のドットモードボタンに切り替えます。

  2. グリッドサイズ（4〜64px）を設定します。これがドット1つのサイズになります。

  3. ドットの色を選択します。

  4. キャンバスをクリックしてドットを置きます。同じマスをもう一度クリックすると消去されます。

  5. クリック＆ドラッグで連続して描画できます。

グリッド表示

「グリッド表示」をオンにすると薄いグリッド線が表示されます。エクスポートした画像には含まれません。

全消去

🗑 クリアボタンで全てのドットを消去します。元に戻すことはできません。

ヒント：テキストモードで文字を入力してからドットモードに切り替えると、テキストの周りにドットアートを描き加えられます。

9. 保存・エクスポート

複数形式でダウンロード可能

ファイル形式

  • PNG — 可逆圧縮。テキスト・シャープな画像に最適。デフォルト推奨。
  • JPEG — 非可逆圧縮。ファイルサイズが小さいが、テキストにはアーティファクトが出やすい。
  • WebP — 高効率の現代的フォーマット。モダンブラウザ全対応。

ダウンロード手順

  1. ドロップダウンから形式を選択します（PNG / JPEG / WebP）。

  2. ⬇ 保存ボタンをクリックすると自動でダウンロードが始まります。

iPhone / iPad の場合

iOSの制限により、画像プレビューのモーダルが表示されます。画像を長押しして「写真に追加」または「イメージを保存」を選択してください。

自動保存

テキスト・フォント・色・エフェクト・キャンバスサイズなどの設定は、変更から約0.8秒後にローカルストレージへ自動保存されます。次回訪問時に自動で復元されます。なお、モードはページを開くたびに常にテキストモードにリセットされます。

リセット

↺ リセットボタンで保存された全設定を消去し、デフォルト状態に戻します。この操作は元に戻せません。

11. よくある質問

本当に無料ですか？ ▼
はい、完全無料です。アカウント登録不要、ウォーターマークなし、使用制限もありません。広告収入によって運営されています。
作成した画像を商用利用できますか？ ▼
はい、作成した画像の権利はユーザーに帰属します。ただし、使用するフォントやコンテンツが第三者の権利を侵害していないかはご自身でご確認ください。
入力したテキストはサーバーに送信されますか？ ▼
いいえ。すべての描画処理はブラウザ上のHTML Canvas APIで完結します。テキストがデバイス外に送信されることはありません。ただし5000兆円モードのみ、画像生成のために外部APIにテキストが送信されます。
ズームするとぼやけて見えるのはなぜですか？ ▼
キャンバスのズームはプレビュー表示のみに影響し、実際の画像解像度は変わりません。ダウンロードされる画像は常に指定した寸法（例：800×600px）のままです。
自分のフォントを追加できますか？ ▼
現時点では対応していません。TextImgはGoogleフォントのセットを提供しています。カスタムフォントは将来のアップデートで追加される可能性があります。
5000兆円の生成に失敗します ▼
このモードは外部API（gsapi.cbrx.io）に依存しています。失敗する場合、APIが一時的に利用できない状態です。しばらくしてからお試しください。
設定が消えてしまいました ▼
設定はブラウザのローカルストレージに保存されています。シークレットモードを使用した場合、ブラウザのデータを削除した場合、または別のブラウザ・デバイスでアクセスした場合は設定が引き継がれません。
